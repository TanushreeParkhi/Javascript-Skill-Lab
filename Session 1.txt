### **What is JavaScript?**

**JavaScript** is a high-level, interpreted programming language primarily used to add dynamic behavior and interactivity to web pages. While **HTML** defines webpage structure and **CSS** handles layout and presentation, **JavaScript** enables pages to respond to user actions, manipulate DOM elements, validate inputs, process data, communicate with APIs, and persist local storage.

#### **Brief History of JavaScript**
* **1995 — Creation:** Created in just 10 days by **Brendan Eich** while working at Netscape Communications. It was initially named *Mocha*, then renamed to *LiveScript*, and finally branded as *JavaScript* to capitalize on Java's popularity at the time.
* **1997 — Standardization:** JavaScript was submitted to ECMA International for standardization, resulting in the **ECMAScript (ES)** specification.
* **2009 — Node.js & Server-Side Expansion:** Ryan Dahl created Node.js, allowing JavaScript to run outside browsers on backend servers.
* **2015 — ECMAScript 6 (ES6):** The release of ES6 introduced major modern features such as `let`/`const` block scoping, Arrow Functions, Promises, Template Literals, Classes, and Modules.

### **Chrome V8 vs. Node.js: How They Differ**

| Feature | **Chrome V8 Engine** | **Node.js** |
| :--- | :--- | :--- |
| **Type** | JavaScript Execution Engine (JIT Compiler) | JavaScript Runtime Environment |
| **Environment** | Runs **inside** the Google Chrome Web Browser | Runs **outside** the browser (on servers/desktops) |
| **Role** | Parses JavaScript code and compiles it directly into native machine code. | Wraps the V8 engine in C++ to provide OS-level capabilities. |
| **Global Object** | `window` | `global` |
| **Available APIs** | DOM APIs (`document`), Web APIs, LocalStorage, Canvas, Fetch. | File System (`fs`), HTTP Server (`http`), OS (`os`), Process (`process`). |
| **DOM Access** | **Yes** — directly manipulates HTML/CSS elements. | **No** — has no DOM or browser window context. |

> **Analogy:** If **Chrome V8** is a high-performance **engine**, **Node.js** is the **entire car** built around that engine, equipped with wheels, steering, and fuel systems (File System, Networking, OS bindings) to run on the open road (servers).

### **Comparing Node.js, Vue.js, and AngularJS**

| Criteria | **Node.js** | **Vue.js** | **AngularJS / Angular** |
| :--- | :--- | :--- | :--- |
| **Category** | Backend Runtime Environment | Frontend Progressive Framework | Frontend Enterprise Application Framework |
| **Execution Site** | **Server-side** (Operating System) | **Client-side** (Browser) | **Client-side** (Browser) |
| **Main Purpose** | Building backend web servers, REST APIs, and command-line tools. | Building interactive user interfaces and Single-Page Applications (SPAs). | Building large-scale, complex enterprise-grade web applications. |
| **Architecture** | Event-driven, non-blocking asynchronous I/O. | Component-based, Virtual DOM, reactive data binding. | Full MVC / MVVM framework with Dependency Injection. |
| **Created By** | Ryan Dahl (2009) | Evan You (2014) | Google (2010 for AngularJS, rewritten 2016) |
| **Learning Curve** | Moderate (requires backend/async understanding) | **Gentle / Beginner-friendly** | Steep (requires TypeScript, RxJS, and strict structures) |
